# LVS v0.4-beta — read-only wallet rebalance preview

This increment observes a selected public Base wallet and manually allowlisted Vault V2s. It calculates indicative USDC target differences. It **cannot prepare, sign, or send transactions**, and printed deltas are not executable amounts.

## Demo (no wallet or RPC needed)

The example policy in the earlier tests is located at data/paper_test_allowlist.json. The repository-wide examples_allowlist.json is intentionally empty; use a policy with selected research vaults.

~~~powershell
.\.venv\Scripts\python.exe -m lapidus_vaults.wallet_plan --demo --allowlist data/paper_test_allowlist.json
~~~

The fictional demo starts with 100 USDC idle, 60 in the first vault, and 40 in the second. At a 20% idle reserve and 40% per-vault cap, targets are 40 idle and 80 in each vault.

## Public wallet read (no keys)

~~~powershell
$env:BASE_RPC_URL = "https://mainnet.base.org"
.\.venv\Scripts\python.exe -m lapidus_vaults.wallet_plan --wallet 0xYOUR_PUBLIC_ADDRESS --allowlist data/paper_test_allowlist.json
~~~

All selected shares and wallet USDC are queried at one pinned Base block. Basic RPC/API vault verification must pass. Share conversion gives estimated USDC values only: no guarantee of withdrawals, price protection, approvals, gas, slippage, adequate liquidity, or protocol transaction validity.

The portfolio value only covers native Base USDC plus the value of shares in the allowlisted vaults. It excludes other wallet tokens/vault positions and ETH gas. Equal targets obey maximum per-vault allocation and idle minimum; if the cap prevents investment, extra assets stay idle.

No private keys or seed phrases are required or accepted. Do not fund a wallet because a dry-run prints a desired deposit.

## Stored data

The wallet_rebalance_previews table records observed amounts, block numbers, selected public wallet address, hypothetical targets, and reasons. It does not store RPC credentials.

~~~sql
SELECT id, observed_at, rpc_block, wallet_address,
       in_scope_capital_units, target_idle_units
FROM wallet_rebalance_previews
ORDER BY id DESC;
~~~

Run the offline suite with:

~~~powershell
.\.venv\Scripts\python.exe -m pytest -q
~~~

## Required before actual capital movement

Independent liquidity/withdrawal checks, ERC-4626 previews, approvals and gas constraints, transaction-level simulation, explicit human authorization for first small deposits/withdrawals, and post-transaction receipt/balance reconciliation. This module must stay disconnected from any signer.
