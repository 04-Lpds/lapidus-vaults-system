# LVS v0.5-alpha — read-only safety planner

The `safety_plan` module is a **non-executable** planning layer on top of the existing `wallet_plan.build_rebalance` allocator.

It builds deterministic intentions, ordered: withdrawals first, USDC approvals only where the observed allowance is insufficient, then deposits. It checks that tentative cash movements balance exactly, validates Base chain and policy deltas, and rejects plans exceeding the supplied cumulative ETH fee ceiling.

It deliberately does **not** encode or sign transactions; it cannot place funds at risk. It does not assert Vault V2 withdrawal liquidity, vault capacity or a network-derived gas estimate. All are future required safeguards before live use.

Try the synthetic offline example:

```powershell
git pull --ff-only
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m lapidus_vaults.safety_plan --demo
```

The demonstration shows Gauntlet withdrawal, Galaxy approval and deposit, and a 20% intended idle reserve. The demo's gas price, ETH availability and indexed block number are fictional; **never interpret these as a live fee quote or verified state**.
